# Recon: Do-er와 비슷한 고완성도 앱의 패턴

복제가 아니라 참고용이다. 남의 화면, 문구, 아이콘, 코드는 가져오지 않고 "무엇을 하는지와 사용자가 어떻게 움직이는지"만 본다.
Do-er의 사업 규칙(AGENTS.md "제품 규칙")과 부딪히는 패턴은 적용하지 않는다.

## Scope

- 대상: Do-er의 핵심 고리(목표 → 날짜별 계획 → 오늘 할 일 인증 → 고른 앱 잠금 → 버거운 날 조정)와 겹치는 앱 여섯 개
- 플랫폼: 모바일(안드로이드 우선, 웹 화면 겸용)
- 쓰임: 실제 테스터 모집 전에 완성도를 끌어올릴 패턴 고르기

## 앱별로 잘하는 것 (Do-er에 쓸 만한 것만)

- **FORFEIT**: 증거를 앱 안 카메라로 그 자리에서 찍게 해 옛 사진을 막는다. 긴 과제는 타임랩스. AI가 먼저 보고 애매한 것은 사람이 본다. 이의 제기 기준을 미리 정해 두고, 진행 중에는 느슨하게 못 바꾼다. 매주 돌아보기.
- **Opal**: 첫 화면에 오늘 상태(점수, 막은 횟수, 가장 많이 손이 간 앱)를 한눈에. 잠금 화면에 짧은 문구. 남은 시간과 상태를 잠금 화면·알림에 계속 보여 준다. 연속 기록을 누르면 조건이 보인다. 이미 답한 질문은 다시 묻지 않는다.
- **one sec**: 잠근 앱을 열려고 할 때 바로 막지 않고 "정말 열 건가요?"를 묻는 짧은 멈춤. 몇 번 멈췄는지, 그만큼 아낀 시간을 보여 준다.
- **StudyLock**: 시작 전에 무엇이 잠기는지 요약 화면. 자료에서 퀴즈를 낸다. 틀린 문제를 다음 학습에 반영.
- **Structured**: 할 일마다 시작 시각과 길이가 있어 하루가 시간 순서로 보인다. 그 시각에 알림.
- **Duolingo**: 연속 기록과 이정표 축하(7일 등). 초반 기록이 크게 느껴지게 한다. 하루 쉬어도 기록이 끊기지 않는 여유 장치가 오히려 꾸준함을 높였다(+0.38%, 자사 발표).

## Core loop 비교

Do-er는 다섯 단계(말하기 → 계획 → 시작 → 인증 → 해제/조정)를 모두 갖췄다. 비교 앱들보다 약한 곳은 셋이다.
1. **하루를 마친 뒤**: 축하, 연속 기록, 주간 돌아보기가 없다. 해냈다는 느낌이 약하다.
2. **잠근 앱을 열었을 때**: 잠금 화면이 "잠겨 있어요"뿐이다. 남은 할 일, 막은 횟수가 없다.
3. **인증의 믿음**: 사진첩의 옛 사진으로도 인증할 수 있다.

| --- | --- | --- | --- | --- | --- |
| S01 | 오늘 | /today | 오늘 몫 | 연속 기록, 오늘 할 일, 시작 | 비어 있음, 시작 전, 잠금 중, 모두 끝 |
| S02 | 다 해낸 순간 | /today 위에 뜨는 창 | 축하와 다음 | 연속 일수, 이정표, 내일 미리 보기 | 첫날, 이정표(3·7·14·30일), 평범한 날 |

| S04 | 잠금 화면(앱) | 안드로이드 덮개 | 잠근 앱을 열었을 때 | 남은 할 일 수, 오늘 막은 횟수, 인증하러 가기 | 첫 시도, 여러 번째 |

| S06 | 잠금 알림(앱) | 안드로이드 상단 알림 | 잠금 중 상태 유지 | 남은 할 일, 인증하러 가기 | 잠금 중, 끝 |

## Flows

```
F01 하루를 끝내기
    S01 오늘 → 인증(마지막 하나) → S02 다 해낸 순간 → S01(모두 끝)
    edge: 여러 목표, 쉬는 날 다음 날, 조정한 날
F02 잠근 앱을 열었다가 돌아오기
    잠근 앱 → S04 잠금 화면 → 인증하러 가기 → S01
    edge: 오늘 몇 번째인지, 화면만 잠근 앱(릴스)
F03 한 주 돌아보기
    탭 → S03 기록
```

## Components

- 연속 기록 배지: 숫자 + 짧은 말. 누르면 조건 설명(인증을 모두 끝낸 날만 이어짐, 조정한 날도 이어짐).
- 축하 창: 아래에서 올라오는 창. 이정표 날에만 조금 더 큰 움직임.
- 주간 막대: 7칸, 끝낸 날·조정한 날·쉬는 날·못 한 날 네 가지 상태.
- 잠금 화면 정보 줄: "남은 할 일 2가지 · 오늘 3번째로 열었어요".

## Inferred data model (Do-er에 더할 것)

```
proofs        이미 있음. 하루 단위로 모으면 끝낸 날을 계산할 수 있다 (confidence: high)
adjustments   이미 있음. 조정한 날 표시에 쓴다 (high)
lock_events   새로. date, target, at. 잠근 앱을 연 횟수. 기기 안에만 두고 하루 합계만 올릴지 결정 필요 (guess)
```

## 적용하지 않는 것 (사업 규칙과 부딪힘)

- Opal의 '쉬는 시간'(타이머 잠깐 풀기), 난이도 낮추기: 잠금을 바로 푸는 길은 없다는 규칙과 부딪힌다.
- Opal의 '앱 삭제 막기': 권한 해제나 삭제를 막지 않는다는 규칙과 부딪힌다.
- FORFEIT의 돈 걸기, 친구에게 문자: 지원서에서 이번 범위 밖으로 둔 것.
- Duolingo의 연속 기록을 돈(보석)으로 살리기: 결제가 없고, 조정이 그 역할을 한다.

## Size

M. 웹 화면 셋(S01 수정, S02, S03)은 며칠, 안드로이드(S04, S05, S06)는 기기 시험이 필요해 더 걸린다.
