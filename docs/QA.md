# QA 체크리스트

결과 표기: 통과 / 실패 / 미점검.

- **로컬**: `node scripts/e2e.mjs`로 실제 브라우저(Edge)를 띄워, 점검용 계정으로 가입부터 탈퇴까지 화면을 직접 눌러 점검합니다. AI와 데이터베이스는 실제 서비스를 씁니다. 점검일 2026-10-14, 32개 항목 모두 통과.
- **배포**: https://doer-app-neon.vercel.app. 배포 사이트에는 점검용 계정을 만들지 않기로 해서, 로그인 없이 확인할 수 있는 항목만 점검했습니다. 점검일 2026-10-14.
- **안드로이드 실제 잠금**은 웹 점검 범위 밖이라 아래 표에 넣지 않았습니다. 가상 폰에서 잠금 화면이 뜨는 것까지 확인했고, 실제 휴대폰 확인은 아직입니다.
