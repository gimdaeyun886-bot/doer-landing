# QA 체크리스트

결과 표기: 통과 / 실패 / 미점검.

- **로컬**: `node scripts/e2e.mjs`로 실제 브라우저(Edge)를 띄워, 점검용 계정으로 가입부터 탈퇴까지 화면을 직접 눌러 점검합니다. AI와 데이터베이스는 실제 서비스를 씁니다. 점검일 2026-11-16, 69개 항목 모두 통과(휴지통 보관·되살리기·완전히 지우기, 다음 계획 대화 추가).
- **배포**: https://doer-mission8.vercel.app. 배포 사이트에는 점검용 계정을 만들지 않기로 해서, 로그인 없이 확인할 수 있는 항목만 점검했습니다. 점검일 2026-11-16(첫 주소는 오늘 화면으로, 로그인 전에는 로그인 화면으로 가는지 확인).
- **안드로이드 실제 잠금**은 웹 점검 범위 밖이라 아래 표에 넣지 않았습니다. 가상 폰에서 잠금 화면이 뜨는 것까지 확인했고, 실제 휴대폰 확인은 아직입니다.

## 과제 필수 시나리오

꼭 확인해야 하는 여섯 가지입니다. 아래 기능별 표와 겹치는 항목도 여기 따로 모았습니다.

| 번호 | 시나리오 | 기대 결과 | 로컬 | 배포 |
|---|---|---|---|---|
| A1 | 빈 값으로 제출 (확인 장에서 목표를 비우고 "계획 만들기") | 저장되지 않고 "무엇을 해내고 싶은지 적어 주세요" 오류 문구, 다른 입력값은 유지 | 통과 | 미점검 |
| A2 | 잘못된 형식의 파일 선택 (PDF, 3MB 넘는 PNG) | 고르는 순간 걸러 내고 "JPG, PNG, WEBP 이미지만", "3MB 이하만" 안내 | 통과 | 미점검 |
| A3 | 등록 후 목록·상세 반영 | 상세로 이동하고, 목록에 새 목표가 보임 | 통과 | 미점검 |
| A4 | 새로고침 후 데이터 유지 | 상세와 목록을 새로고침해도 같은 내용 | 통과 | 미점검 |
| A5 | 수정 후 화면 반영 | 바꾼 제목이 상세와 목록에 보이고, 계획을 다시 짬 | 통과 | 미점검 |
| A6 | 삭제 후 화면 반영 | 확인 창을 거쳐 지우면 목록에서 사라짐 | 통과 | 미점검 |
| A7 | 존재하지 않는 상세 주소 (지운 목표의 주소, `/goals/abc`) | "목표를 찾을 수 없어요" 화면 | 통과 | 미점검 |
| A8 | 파일이 없는 경우 | 자료 사진 없이 등록한 목표의 상세에 "올린 자료가 없어요" 안내 | 통과 | 미점검 |
| A9 | 파일을 올린 경우 | 수정에서 올린 자료 사진이 Storage에 저장되고 상세에 보임 | 통과 | 미점검 |
| A10 | 업로드에 실패한 경우 | 저장소 오류 시 "사진을 올리지 못했어요" 안내, 입력값 유지 | 미점검 | 미점검 |

A10은 저장소 오류를 일부러 일으키는 방법이 없어 점검하지 못했습니다. 형식·크기가 틀린 파일은 A2처럼 올리기 전에 막고, 서버에서도 한 번 더 검사합니다.
