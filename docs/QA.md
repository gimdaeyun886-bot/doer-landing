결과 표기: 통과 / 실패 / 미점검. 로컬은 `npm run dev`, 배포는 Vercel 배포 URL에서 점검합니다.

19번과 20번을 뺀 항목은 `node scripts/qa.mjs <주소>`로 실제 브라우저(Edge)에서 자동 점검합니다. 로컬 점검일: 2026-10-11.
