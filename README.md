# Do-er 랜딩 페이지

**배포 URL:** https://doer-landing-nine.vercel.app

## 서비스 소개

Do-er는 "계획은 세우는데 실행이 안 되는" 사람을 위한 AI 실행 코치입니다.
첫 대상은 퇴근 후 자격증 시험을 준비하는 직장인입니다.

1. **계획** — 목표와 시험일을 말하면 AI가 전체 계획을 짜고 오늘 할 일로 나눕니다.
2. **잠금** — 시작하면 내가 고른 방해 화면(릴스·쇼츠·스토리 등)이 잠깁니다.
3. **인증** — 끝낸 일을 인증하면 잠금이 풀립니다. 인증 방법은 미리 정해져 있지 않고 과제마다 AI가 맞는 방법을 찾습니다.
4. **조정** — 버거운 날에는 코치에게 사유를 말합니다. 코치가 조정안과 그 대가(완료일 연장 또는 남은 날에 분량 추가)를 함께 보여 주고 사용자가 수락하거나 유지합니다.

이 저장소는 위 흐름을 소개하고 베타 수요를 확인하기 위한 랜딩 페이지입니다.

> 이 페이지의 폰 체험은 준비된 예시입니다. 가입·결제·실제 AI 판정·기기 앱 차단은 실행하지 않으며 베타 신청은 아직 열지 않아 개인정보를 전송하지 않습니다.

## 기술 스택

- HTML, CSS, JavaScript (프레임워크·빌드 도구 없음)
- Web Animations API, IntersectionObserver, ResizeObserver
- 글꼴: Gothic A1 (자체 호스팅 woff2, SIL OFL)
- 배포: Vercel (정적 사이트)

## 구현한 인터랙션

- **폰 체험 데모** — 목표 입력부터 오늘 할 일, 시작(잠금), 과제별 인증, 전체 완료(잠금 해제)까지 11번의 클릭으로 이어지는 체험. 화면 전환, 맞춤 인증 방법 탐색, 체크·진행 원, 자물쇠 해제 애니메이션 포함
- **코치 조정 경로** — "오늘 계획이 버거워요"를 코치 대화에서 말하면 조정안을 제안하고 수락하면 오늘 할 일과 주간 계획에 반영
- **스크롤 색 전환** — 밤(어두운 배경)에서 아침(크림 배경)으로 스크롤 위치에 따라 서서히 바뀌는 테마
- **스크롤 등장 연출** — 달력 칸 채움, 타임라인 진행, 주간 차트 막대와 숫자 카운트
- **장면 연출** — 침실·공부 캐릭터 그림 위의 가벼운 움직임
- **모바일 메뉴, FAQ 펼침**
- **접근성** — 움직임 줄이기 설정에서는 최종 상태만 표시, 화면 밖·숨긴 탭에서는 반복 움직임 정지

## 실행 방법

설치 없이 실행됩니다.

- `index.html`을 더블클릭해 브라우저에서 엽니다.
- 또는 로컬 서버로 엽니다.

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000` 을 엽니다.
